# thendar-git.github.io

The website for [Word Jungle](https://github.com/thendar-git/Word-Jungle), served by GitHub Pages at https://thendar-git.github.io.

- `index.html`: home page.
- `privacy/index.html`: privacy policy (https://thendar-git.github.io/privacy/). It is linked from Play Console and from the app.
- `app-ads.txt`: AdMob's authorized-seller file. It must stay at the site root.
- `assets/`: stylesheet, icon and screenshots (from the game repo's `store/` and `store-assets/`).

Plain HTML and CSS with no build step. Edit a file, push to `main`, and Pages republishes in about a minute.
